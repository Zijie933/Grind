# 两日哑铃计划

器材：哑铃、健身椅。一周练 2–3 次。两天合在一起覆盖图里的全部部位：胸、背、肩、臀腿、肱三头、肱二头、前臂、小腿、肩袖、腰腹。

大肌群每组 8–12 次，手臂、小腿和腹 10–15 次。最后两次要费劲，动作不散。卧推、划船、深蹲组间休息约 90 秒，手臂和腹约 60 秒。一组能做满次数再加重。

## 怎么排周

- 一周 2 次：训练日 A，隔 1–2 天，训练日 B。
- 一周 3 次：这周 A、B、A，下周 B、A、B。每次隔一天。

## 训练日 A：大肌群

练到：胸、背、肩前束和中束、臀腿。

| 部位 | 动作 | 组 × 次 |
| --- | --- | --- |
| 胸 | 哑铃卧推 | 3 × 8–12 |
| 胸 | 哑铃上斜卧推 | 2 × 8–12 |
| 背 | 单臂哑铃划船 | 3 × 8–12 / 侧 |
| 背 | 俯身哑铃划船 | 2 × 8–12 |
| 肩 | 哑铃推举 | 3 × 8–12 |
| 肩 | 哑铃侧平举 | 2 × 12–15 |
| 臀腿 | 高脚杯深蹲 | 3 × 8–12 |
| 臀腿 | 哑铃直腿硬拉 | 3 × 8–12 |

## 训练日 B：剩下的上肢 + 腹 + 小腿

练到：肱三头、肱二头、肩后束、前臂、肩袖、小腿、腰腹。

| 部位 | 动作 | 组 × 次 |
| --- | --- | --- |
| 肱三头 | 颈后哑铃臂屈伸 | 3 × 10–15 |
| 肱二头 | 哑铃弯举 | 3 × 8–12 |
| 肱二头 / 前臂 | 哑铃锤式弯举 | 2 × 10–15 |
| 肩后束 | 俯身哑铃侧平举 | 2 × 12–15 |
| 前臂 | 背后腕弯举 | 2 × 12–15 |
| 肩袖 | 哑铃过顶前平举 | 2 × 12–15 |
| 小腿 | 哑铃单腿提踵 | 3 × 12–15 / 侧 |
| 腰腹 | 负重卷腹 | 3 × 10–15 |
| 腰腹 | 平板支撑 | 3 × 30–45 秒 |
