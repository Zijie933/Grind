# 两日哑铃计划

器材：哑铃、健身椅。一周练 2–3 次。动作从图里的哑铃清单里选，大肌群每组 8–12 次，手臂和腹 10–15 次。最后两次要费劲，但动作不散。卧推、划船、推举组间休息约 90 秒，手臂和腹约 60 秒。一组能做满 12 次再加重。

不含臀腿。这两天只分上肢和腹。

## 怎么排周

- 一周 2 次：训练日 A，隔 1–2 天，训练日 B。
- 一周 3 次：这周 A、B、A，下周 B、A、B。每次隔一天。

## 训练日 A：上肢大部分

胸、背、肩。大约 50 分钟。

| 动作 | 组 × 次 |
| --- | --- |
| 哑铃卧推 | 3 × 8–12 |
| 哑铃上斜卧推 | 3 × 8–12 |
| 单臂哑铃划船 | 3 × 8–12 / 侧 |
| 俯身哑铃划船 | 3 × 8–12 |
| 哑铃推举 | 3 × 8–12 |
| 哑铃侧平举 | 2 × 12–15 |

## 训练日 B：腹 + 剩下的上肢

肱三头、肱二头、肩后束、腹。大约 40 分钟。

| 动作 | 组 × 次 |
| --- | --- |
| 颈后哑铃臂屈伸 | 3 × 10–15 |
| 俯身臂屈伸 | 2 × 10–15 |
| 哑铃弯举 | 3 × 8–12 |
| 哑铃锤式弯举 | 2 × 10–15 |
| 俯身哑铃侧平举 | 2 × 12–15 |
| 负重卷腹 | 3 × 10–15 |
| 平板支撑 | 3 × 30–45 秒 |
